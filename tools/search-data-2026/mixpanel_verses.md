## Caveats

- Web chapter-1 sequential artifact: 26 of the top 30 web verses are 1.x (the other four are 2.1, 2.2, 2.3 and 2.47) in reading order (1.1 552 users, then steadily declining). This is the Next-verse reading path from /gita, not interest in those verses. Use the external-entry list for "what readers sought out".
- 93% of web verse views (6,408/6,893) have an internal wisdomquotes.in referrer.
- 2.47 external entries include ~15 users referred by reddit (single-thread effect likely).
- Web 2.1: 31 external-entry views from only 3 users (repeat reloads).
- $mp_actor_type is only populated from Sep 2026; before that bots are unlabelled. Linux exclusion removes what looks like a crawler that hit almost every Hindi verse once plus fake spikes (hi 17.22: 89/89 users Linux; hi 3.42: 41/44; 11.12: 36/36). Some unlabelled Windows/Mac bots from May-Aug may remain.
- Small samples: web per-verse users mostly < 40 outside 1.1-1.5; app max 5 users per verse. App ranking is not statistically meaningful.
- App opens are recommender/widget-pushed; no event shows a free browse or search of the Gita in the app (SettingsScreenGitaPressed: 2 events in 30 days), so app counts measure exposure, not choice.
- App content DB has duplicate rows for the same verse (e.g. 6.35 has two UUIDs); taps are summed per c.v so tap users are upper bounds.
- Unique users are distinct_ids; EN+HI or web+app are not deduplicated across projects.
