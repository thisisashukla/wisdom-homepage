## Caveats

- GSC withholds rare/anonymised queries. Only 12,163 of the property's 67,682 impressions (18%) carry a visible query, and only 1,759 of the 11,897 verse-page impressions do. Query-level totals therefore undercount page totals heavily; a verse with zero matched queries can still have meaningful page impressions.
- This measures what Google showed wisdomquotes.in for, not total search demand. Verses where the site does not rank (or ranks below where impressions are counted) are invisible; the site's verse pages only started receiving impressions on 2026-05-10.
- Impressions are counted when a result is shown, often for low positions (many verse pages average position 8-12); a single searcher paginating can create several impressions.
- The page,country table is restricted to query-attributed traffic (sums to the same 12,485 as query,page), so the page-level country split covers only ~15% of verse-page impressions. Use the query-level split for the story.
- Chapter 13 numbering: this corpus has 35 verses in chapter 13 (13.1 = Arjuna's question, omitted in many 700-verse editions). A searcher typing "bg 13.29" may mean this corpus's 13.30. Chapter-13 numeric matches are kept as typed and flagged (chapter13_numbering_note).
- Bare number queries ("9.23", "15.7") are included only when GSC served that verse's page for most of their impressions, which biases toward verses the site already ranks for.
- Small numbers: most verses have single-digit query impressions; rank order below ~top 15 is noisy and should not be over-interpreted.
- data_state=final excludes 2026-10-27; re-running the same calls later can shift numbers slightly if Google revises data, so the raw API responses and their sha256 are kept alongside.

Method, raw API responses (sha256) and every matched/dropped query are in gsc_verses.json.
